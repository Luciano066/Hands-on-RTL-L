# Intenção de potência futura

Diretório reservado para UPF se o fluxo e a arquitetura escolhidos precisarem descrever domínios de potência, isolamento, retenção e estados de alimentação. Baixo consumo é objetivo final, sem técnica ou meta numérica fixada na Semana 1. Não há UPF, power gating ou clock gating implementado nesta entrega.
